Reading guide & exam conventions

Original practice questions to accompany your two main readings:

  • RareSkills — Mastering Uniswap V3: price representation, ticks, real and virtual reserves, and positions.
  • Uniswap V3 Development Book: work through milestones 1–6, from the first swap to NFT positions.
  • Production V3 core and V3 periphery: the reference when a teaching implementation simplifies behavior.

Unless stated otherwise, questions refer to production V3 core and the original V3 SwapRouter / NonfungiblePositionManager. P means raw token1 units per raw token0 unit; s = √P. Human-readable decimal conversions, ignored fees, and ignored rounding are stated explicitly.

Six questions per topic, one correct answer each. Every answer includes an explanation and a source to revisit. Best scores stay in this browser; an unfinished attempt resets on reload.
